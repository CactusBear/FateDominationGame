# source_3 卡面 Operation 审计（1161–1740）

## 范围与口径

- 已依次全文审阅 `source_3.md` 的 580 条转录（1161–1740），包含当前版、旧版、DIY、Token、卡背及从者概览；**没有按版本排除**。
- 结论来自现有 OCR 转录与源码静态核对；**未查看或声称查看原图**。
- 已核对 `assets/scripts/system/operations/*.gd`、`assets/scripts/system/global/all_operations.gd`，并把当前工作树中的 `CreateCard.gd` / `BuildCard.gd` 纳入现有能力。
- `SetProperty` 只会写已存在属性；它不会补齐区域归属、效果登记/注销、威力同步、历史日志或 UI 生命周期。因此下文不把“字段能写”误判为“底层机制已支持”。

## 结论摘要

本批卡面大量数值增减、抽弃牌、按属性筛牌、移动、真名显隐、延迟至下回合、一次性限制与换御主/从者，能由现有原语组合。真正重复出现且不能安全组合的缺口集中在：数组窗口查询与聚合、卡下附着区、非事件牌放置、卡面切换、效果文字禁用/恢复、控制权转移、指定能力重放、地图图查询、数值取整与特殊数论、玩家复活/回合重开，以及来源可追踪的力量修正。

## 新增候选（单一职责）

| 候选 | 精确卡面编号与卡名 | 为何现有原语不足 | 可复用组合 |

| `get_array_slice(arr, start, count)` | 1162/1163「太阳石」；1304/1307/1309「女王的灵香」；1419/1424「选定之杖」；1332「三十六歌仙」 | `get_card_by_index_fr_arr` 一次只返回一张；`for_func` 只返回最后一次结果，当前没有纯查询式收集器，无法把动态 X 张牌交给选牌 UI 或后续排序。 | 得到窗口后，以 `draw_card_by_card(..., to_index)`、`add_to_array`、`shuffle_array` 完成选择、放顶/底与洗牌；不另造“占卜”“预言”角色专用操作。 |
| `sum_property(objects, property)` | 1182「阿国十八番·出云荒神歌舞伎」；1505/1507「机关幻法·吞牛」；1614「闪耀于终焉之枪」；1673/1679「化身·伊吹大明神缘起」 | `foreach_func` 没有累加器，`get_extreme_by_property` 只能取一个极值，不能求印刷威力、事件战果等动态总和。 | 用 `get_property` 指定 `_power`/事件战果等字段，再接 `calculate_number`、`edit_power`、`edit_score`。 |
| `count_distinct_values(values)` | 1182「阿国十八番·出云荒神歌舞伎」；1333「源氏物语」；1673/1679「化身·伊吹大明神缘起」 | 现有集合只有长度、包含、差集、合并，没有去重/不同种类计数；逐卡用角色专用分支会重复。 | 先用 `get_card_attributes` / `get_property` 取得值，再计不同值；阈值判断继续用 `compare_number`。 |
| `round_number(value, mode)` | 1216「为你撰写的故事」（战果÷5向上取整）；1745（下一批同机制）外，本批 1216 是直接需求 | `calculate_number` 支持四则、余数、min/max，但不支持 floor/ceil/round。 | `calculate_number` 先除法，`round_number` 只负责取整。 |

| `set_object_effects_enabled(object, enabled)` | 1203–1205「禁忌狂宴／猪化」；1314「傀儡游园」；1438「残光、令人憎恶的血之城塞」；1555–1565「死告天使／幸运失去文字」；1605「对灵魔术」 | `unregister_object_effects` 只处理已登记效果；手牌/牌库中未来可发动的效果、关键词、打出条件仍在。直接 `set_property("_effects", [])` 会丢失原效果且无法恢复，也不会同步当前登记。 | 底层应保留原定义并统一让出牌、主动效果、被动监听查询 enabled；启停后仍复用登记/注销原语。 |
| `switch_card_face(card, target_definition)` | 1615「魔术礼装·亚德」；1710–1713「不辍之书／真祖咏叹／咒血尸解叹歌」 | 改图片、名称、属性、费用、威力、效果数组中的任一字段都不等于完整切换；旧效果需注销、新效果需绑定到同一实例并登记，当前没有原子生命周期入口。 | 目标定义可由 `create_card` / `build_card` 创建；候选只负责把现有实例安全切面，不负责放区或打出。 |
| `invoke_card_effect(card, effect_name)` | 1329「献给某人的故事」（无视前提触发一次童话具现被动）；1670/1672「女武神的叙语」（再次使用打出时/行动/战斗能力） | `emit_time_point` 会广播时点，不能只执行指定牌的指定能力；直接取 `_funcs` 执行会绕过费用、次数、选择与日志。 | 仍由 `BaseEffect` 的现有选项、次数与费用系统结算；候选只做“定位并请求发动指定效果”。 |

## 框架缺口（不应伪装成一个 Operation）

1. **卡下附着/封印/齿轮/谜/毒/蛇的通用区域模型**：1220–1222「埋葬」、1232–1233「齿轮」、1247/1249「启示」、1298–1300「封印」、1336/1348/1353/1354「牌置于技能上」、1648/1651「毒」、1674–1677「蛇」。`BaseCard` 没有通用 attached zone；先定义所有权、公开性、离场去向、克隆语义，再谈搬运 operation。
2. **非事件/非 Buff 对象放置到战场**：1196/1199「螺湮城教本」、1203–1205「禁忌狂宴」、1314「傀儡游园」、1497「姬路城」、1725「阿尔托莉雅之星」。`BaseMapArea` 现有入口只覆盖 `_events` 与 `_buffs`，技能/攻击放置物没有容器与生命周期。
3. **持续保护与目标替换协议**：1185「大封印结界阵」、1291「白之圣杯」、1401「金苹果」、1437–1440「阿纳斯塔西娅」、1601「幻术（外术）」。`counter` 只能处理当前效果，系统缺少“某对象是否可被某来源影响”的统一 targetability/interception 层。
4. **来源可追踪的力量修正**：1245「苍天已死，黄天当立」、1340「梦幻召唤·剑士」、1605「对灵魔术」、1612–1614「格蕾武装」。当前威力数值没有完整保存“来自局势/事件/令咒/某卡”的来源账本，无法安全反转、翻倍或只清除某来源。
5. **玩家淘汰/复活/从者死亡生命周期**：1436「真药·无用的冥府悲叹」、1549/1553「告死天使」。`set_player_data("is_out", false)` 不会恢复顺位链、版图、牌区、效果登记；“杀死从者后随机换从者”还需卸载旧牌并重发新牌。
6. **整回合回滚/重开**：1319/1322/1328「永久少女·机关帝国／无名森林」。现有日志是查询记录，不是可逆快照；需要阶段机、随机状态、选择记录及所有区域的事务快照。
7. **同时秘密投票与倒计时选择**：1536/1541「死亡将为明日的希望」。这是多人 UI/网络同步协议，不应塞进一个规则 operation。
8. **临时复制技能并改写文案中自指名称**：1347/1363「照耀星天的地之朔月」、1653–1655「十面埋伏」。`clone_object` 可复制对象，但“文案提到名字时视为自己”必须依赖结构化引用，不能字符串替换。

## OCR / 转录问题

- 明确无文字或无法识别：1215、1353、1372、1391、1461、1522、1523、1542、1724、1734、1735、1737、1738。
- 仅识别出 Token 数值/符号、不能据此推导规则：1733、1736（“+3”）；这些按 `non_rule` 记录，不把数值猜成效果。
- 复杂版式存在明显错位/符号丢失，虽可识别机制但实现前必须回看原图：1229/1231「机械铠甲」、1354「照耀星天的地之朔月」、1597「杀戮机巧」、1616「焦骨牡丹」、1673「化身·伊吹大明神缘起」。
- 旧版与新版同名但数值/时点不同（例如 1203–1205、1495/1502、1548–1554）；审计保留全部条目，不合并为“同一张”。

## Coverage

逐条状态与机制标签见 `coverage_3.json`。状态只使用 `analyzed`、`unclear`、`non_rule`；从者概览、纯牌背/Token、无规则文字的基础牌记为 `non_rule`，OCR 无法恢复语义的条目记为 `unclear`。
