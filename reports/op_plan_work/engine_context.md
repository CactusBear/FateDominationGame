# 引擎上下文（FateDominationGame, Godot 4 GDScript）
效果 = JSON：effect 有 time_points(时点)、funcs(按序执行 operation，func_name 下划线→operations/<PascalCase>.gd 的 exec)、var_index(结果存变量表)、condition({"self_var":N} 控制执行)、is_manual(玩家主动)、need_activate、is_pure_passive、is_residue(残留)、once_per_game、source_bound、expire_time_points、cost、effect_numbers(规则数字)、power_query(只读合计威力表达式，局势/事件牌用)。
选项 options：shown_option_name/funcs/max_uses/quantity_range/tags/activation_requirements(发动前置查询)，
 以及延迟输入：select_cards{source(player_data键如hand_cards/deck/discard),owner:"target_player",min,max,attributes,max_power}、select_players{candidates(func求值得id数组),min,max}、select_location{allowed_origin_areas,forbidden_target_areas}。选中结果在 effect._selected_cards/_selected_players/_selected_player/_selected_location（可 get_property 读）。
 效果级：max_choices、max_total_uses、reset_counts_each_round、consumes_source_resource。
系统效果类(按效果名被规则入口查询)：cannot_play_cards、counts_power_while_concealed、excluded_from_battle_win、forbid_noble_phantasm、forbid_special_attack、never_counts_power、no_location_benefit。buff：defeat_buff（败北）。
玩家数据 player_data 键：master servant command_spell magic score lives deck discard hand_cards played_cards master_skills servant_skills location temp_locations power is_victory is_out is_shown is_battle order buffs self_effects out_of_game{master,servant,command_spell,attacks,skills,buffs,others} side{...} command_spell_count command_spell_limit used_once_effects play_limit regular_play_min can_draw_card action_requirements last_turn_location is_magic_immune ignore_skill_zone_magic_limit ignore_engagement_for_move total_power_bonus attack_cost_discount move_cost_discount_from_workshop victory_override。GameData.magic_limit(魔力上限)。
卡字段：BaseCard{_name,_shown_name,_card_img,_effects,_attributes,_is_concealed,_relate_buff,_keywords,_initial_zone}；BaseHandCard{_cost,_power,_is_activating,_is_closed,_cost_discount,_play_requirements,_need_extra_play(需追加打出),_modification_history}。地点 BaseLocation{_players,_magic,_benefit(地利),_pl_num_limit,_can_deploy}；战区 BaseMapArea{_locations,_area_name,_events,_score,_buffs,_linked_map_area,_move_cost,_can_move_to}。MapData{situations,active_situation,event_deck,event_discard,situation_discard,areas}（注意：MapData 的牌堆目前没有 getter operation，get_game_data_value 只读 GameData）。
时点(可加 self_/others_ 前缀)：game_start/end, prepare_phase(_start/_end), outpost_phase(前哨), action_phase, battle_phase, day_start/day_end(回合始末), played_card, magic_add/decrease, score_add/decrease, eliminated, battle_win/battle_lose/battle, battle_resolve(战力结算), card_revealed, battle_end, climax(高潮)/non_climax, deploy, move(_start/_end), effect_start/end, buff, true_name_release/true_name_hidden 等。
日志：query_log/log_exists/sum_log_data/log_field_values 可查历史事实（出牌、移动、令咒使用、效果触发…）。

## 已知组合惯例
- 牌堆顶/底/第N张/随机插入：draw_card_by_card/draw_card_by_index 的 to_index(0顶,-1底) + random_int。
- 移出游戏：find_player_array_containing → draw_card_by_card 到 get_pl_attacks_out_game/get_pl_skills_out_game。
- 创建临时牌/复制：create_card(库名)/build_card(完整数据)/clone_object → add_attack/add_skill/play_attack 入场；"临时"=配 schedule_effect_on_time_point 在 day_end 移出。
- 计数标记（【浪】【境界】等）：create_buff + manage_buff，层数用 BaseNumber/edit_num_and_return 或 set_player_data 自定义键 + edit_data_number。
- 每局一次：used_once_effects + is_in_array/add_to_array 或 once_per_game。
- 延迟/直到回合结束：schedule_effect_on_time_point(时点,funcs,priority,require_all,expire)。
- 循环累加：foreach_func/for_func/while_func + edit_num_and_return 外部 BaseNumber。
- 换御主/从者：unregister_object_effects→set_player_data→register_object_effects→deal_player_cards。
- 胜利覆盖：set_player_data("victory_override",true)（仅最终结算）。
- 选择：options + select_cards/select_players/select_location；执行中临时询问 ask_player_option(options,...)。
- 反制：counter(effect,func)；关闭时点 close_time_point。
- 修改属性 edit_card_attributes；威力 edit_card_power；费用 edit_card_cost；某属性威力按0 zero_attribute_power；按属性加减 modify_attack_power_by_attribute。
- 败北 defeat；真名 release_true_name/hide_true_name；关闭 close_card；明暗 set_card_concealed；移动 move/move_location/set_location；部署 deploy。
