# 旧恢复档显式管理员迁移（静态交付）

本批只修改本机控制台的命令注册、帮助和处理器，网关的独立旧档管理方法，新增迁移执行器与静态检查。不得修改身份模型核心、大厅主流程、worker、UI、effect；不启动 Godot、不读取凭证、不提交 commit。

## 代码职责
- `room <id> legacy-approve <pid> <instance_id> legacy_approved '<成员编号到认证连接编号的JSON对象>'`：只由可信本机控制台调用。成员编号沿用旧档稳定编号，管理员必须明确选择全部成员与当前已认证连接的对应关系；不接收公钥、指纹、票据、路径。网关从连接认证表与登记库重新建立指纹映射。旧房主的映射必须经过已有 prepare_legacy_bindings 校验。
- `room <id> legacy-reject <pid> <instance_id>`：显式拒绝；原恢复档、目录、配置和存档不改，不启动恢复。留下仅含成员编号和固定操作人标签的拒绝记录。
- 网关验证 room ID、PID、instance_id、authority_host_mode 与当前登记和磁盘配置一致；只允许工作进程已停止，避免 worker 并发覆盖。旧实例或活跃进程直接拒绝。认证失效、重复连接、跨房间连接、字段混入、遗漏成员全部失败关闭。
- 复用 member_identity_bindings 的纯事务准备（不调用其不安全的直接覆盖写盘方法），生成全部新随机票据，磁盘只保存哈希。候选先写同目录随机临时文件、flush、读取验证，再比较原文件字节。Windows 使用 .NET File.Replace 的原生原子替换并保留随机备份；其他系统使用同目录 rename。禁止用 Windows DirAccess.rename 覆盖原档。失败不把迁移报告为成功。
- 成功落盘且读回一致后才对每个当前认证连接私有单播票据；控制台回执只返回成员编号和交付失败数量，不返回票据或身份指纹。发送失败明确报告“落盘完成但交付未确认”，不伪报恢复完成。
- 审计只记录成员编号、批准/拒绝与固定 `local-console` 操作人标签，不记录认证指纹、密钥、token、完整命令。拒绝自动认领、昵称匹配、公网 args 提供指纹和直接调用旧档覆盖方法。

## 静态验证
新增 GDScript 命令解析反例夹具与 Python 源码结构检查，检查参数数量、审批标记、映射类型、重复连接、非法成员编号、公网入口隔离、写盘先于私有交付和敏感回执边界。可用 gdtoolkit 时仅执行静态解析；不把静态结果表述为 Godot 运行或原子替换的实机验收。
