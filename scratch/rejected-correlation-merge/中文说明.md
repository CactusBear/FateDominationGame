# 拒绝回执精确关联安全合并

只修改 group_selection.gd、v2_view_presenter.gd、network_choice_panel.gd、lobby_session.gd 的请求/拒绝相关片段，保留当前 UI 可用性刷新、服务器通知和身份继承改动。不修改 gateway、worker、effect、transport，不运行 Godot，不访问凭据，不提交 git。

先对现有 correlation.patch 逐片段核对当前源码并执行 git apply --check。补丁位于 Hermes cache/scratch/rejected-request-correlation-v2，不在仓库 scratch。

会话保留 rejected(reason) 供原提示使用，新增 request_rejected(seq, reason) 专供精确解锁。seq 复用信封序号，不把 view_seq、预览 request_id 混作请求身份。request 在发送之前调用登记回调，兼容房主同步拒绝；序号耗尽直接失败，不自动重试、不增加预算。权威请求拒绝原样回传本请求正整数 seq，异步错误默认不携带关联号，旧无 seq 错误仅提示。

组合提交及预览各保存当前信封 seq，仅对应拒绝解除锁；迟到预览不恢复已拒请求。guard 同时检查信封 seq 和当前视图。私有待答 changed 仅在真正改变提示或视图时清旧请求；相同状态的无关 changed 保留提交锁及原选择。所有本地发送失败走显式解锁，不伪造权威拒绝。

新增 GDScript 专项反例源码：使用真实组件及受控会话信号，覆盖无关/过期拒绝、无关 changed、同步回执登记、预览拒绝和旧无 seq 提示。仅做 gdtoolkit 静态解析，不能宣称 Godot/网络/窗口运行通过。
