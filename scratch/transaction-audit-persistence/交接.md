## 主代理必须对账的边界
- EffectManager 的 start/child/pause/tail_registered 旧调用点有忽略 audit 返回值的情况；它由兄弟代理独占，本代理没改。必须由其消费失败/保持暂停，否则本代理的持久化层无法保证所有普通规则入口立刻停算。管理跳过路径已消费。
- 旧版本 2 审计缺少命名空间/收据，安全拒绝，不自动迁移或重算历史。无审计旧规则存档仍可只读恢复，但不能声明完整审计另存/续写。
- 生命周期 pause/resume 以根作用域最后事实与语义载荷区分阶段；同一阶段重试幂等。调用方若需要在没有任何中间事实的情况下记录两个语义完全相同的暂停，须提供显式调用代数（当前旧 API 没有该参数），不能以时间猜事件身份。
- mkdir 租约崩溃遗留不会自动抢占；管理员确认原写入者退出后手工移除具名 .writer-lock 目录，再重新验证完整链。避免误删仍活跃租约。
- Crypto 随机命名空间是工程唯一性，不声称数学零碰撞；SHA-256 不是认证；FileAccess.flush 不声称硬件断电保证。同进程互斥/跨进程协作租约不抵抗恶意绕过锁、同长度修改或符号链接别名。
