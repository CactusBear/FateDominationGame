# 根事务独立审计持久化实施说明

本代理仅修改 match_journal.gd、match_replay.gd 及实际位于 scripts/net/match_authority.gd 的事务管理接线，不修改 EffectManager、EffectCheckpoint、worker、网关和 UI。不启动 Godot、不读取凭证、不提交。

复用现有长度帧、序号和 SHA-256 链；规则 match.log 的格式和动作记录不改。审计增加独立格式版本、密码学随机进程命名空间与根局部 ID 组成的 transaction_id，局部整数 API 保持兼容。审计原因只映射到公开白名单代码，未知文字统一 redacted，不保存牌名、参数、票据或指纹。

对审计写入加进程内互斥以及跨进程原子目录租约，租约冲突明确拒绝，崩溃遗留租约不自动抢占。同一语义事件重复调用返回原成功，不增加序号；待答暂停等生命周期以显式阶段区分。审计累计字节、记录数和单帧容量显式拒绝，不隐式删除/轮转历史。写入、flush 和容量失败锁定失败状态；真实回滚前后消费审计失败，禁止生成成功管理事实。

回放执行只在隔离内存中模拟审计边界，不向不可回滚审计写入；另存必须复制完整真实审计而非裁剪其历史。审计可能超出规则末尾（例如意图已写而规则写失败），此时同源续写拒绝。新增 GDScript 专项源码覆盖重复、隐私、容量、损坏和租约拒绝，交付只承诺静态解析，运行红绿由主代理串行执行。

边界：随机 256 位命名空间提供工程意义的跨进程唯一性，不声称数学零概率；目录租约为协作写入者互斥，非对抗访问控制。Godot FileAccess.flush 不提供硬件断电持久性保证。SHA-256 链不是认证签名。
