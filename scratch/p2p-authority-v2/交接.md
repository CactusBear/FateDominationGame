## 必须继续的主代理验收/接线

1. authority_host_mode 仅本模块显式诊断声明；worker 子进程的实际机器/PID 接线属于权威 worker 代理。本代理读到 P2P/LAN 原会话仍在房主进程计算，不能宣称本批已实现隔离权威子进程。请核对 LAN/邀请码/信令 host 入口均在房主机器启动 worker，独立服务端在 server 机器，relay-only 永不启动。
2. 信令只能交换 offer/answer；STUN 是 WebRTC 配置服务，此模块不实现自建地址反射/STUN 服务器，不能宣称 relay 已提供自建 STUN。
3. 新 Godot 专项未运行（用户禁止），gdtoolkit 只语法解析，不验证 Godot 成员/API/类型。主代理获准后串行新增专项及 net_p2p_signal_client_test、net_p2p_expiry_direct_test、net_p2p_guard_rollback_test，关闭信令后发真实游戏业务。
4. 客机 reply 白名单与新 send 返回值需真实 WebSocket/WebRTC 回归；信令失败无游戏转发兜底。
5. 公网、异地 NAT、selected pair、TLS、实际进程位置都尚未验收。公网夹具是证据规格+完整性校验器，不是自动跨网运行器；必须现场 H/G/R 实测。未知 NAT 继续尝试，不靠推测拒连。
6. 密钥不匹配由已认证房主指定继承者，属于身份代理接线；信令房间码从未授予规则权限。
