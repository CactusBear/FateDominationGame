# 导出前最终联机缺口审计 v5

## 结论

**当前不可作为“完整联机可发行”版本放行。最直接阻断是 `ServerRoomManager.process_ownership_available()` 固定返回 false，正式 LAN/P2P/独立服务端创建房间均不能成功。** 这是安全失败关闭，不是应删除的校验；必须实现原生进程所有者后再开放。另有预检子进程裸 PID 管理、独立服务端恢复非失败原子、对局身份继承入口缺失等代码缺口，不能交给真人测试替代修复。

本轮只读生产扫描，新增本目录报告/JSON；**未运行 Godot、未导出、未读取或操作凭据、未 commit、未改生产**。所有动态结论均为 NOT_RUN。仓库已有大量未提交修改，本扫描不是冻结版本；扫描后 `p2p_signal_client.gd`、`enet_transport.gd` 指纹已变，说明其他写入者仍在活动。最终准入必须停止写入者后重新对账。

对当前 net 的 54 个 GDScript、25 个信号声明检索消费者，再复核关键生产链，未把“外部零引用”直接判成断线：

- gateway.send_failed 外部零消费者，但同脚本 `_init` 已 connect `_log_transport_diagnostic`，不是空信号。
- session.data_management_requested 在 server_data_approval.configure 连接，处理器为空时请求明确拒绝；catalogs_changed 同组件消费，不是静默放行。
- group_preview_received→group_selection，request_rejected→group_selection/network_choice_panel/v2_view_presenter；server_notice_received 大厅与 v2 都接入。
- inheritance_candidates_received 由现有 panel 消费，inheritance_ticket_received 只由大厅消费：真正缺的是中局正式入口，不是协议不存在。
- blob 完成与缓存读取需区分信号驱动和同步轮询；缓存/room_data_sync 的现成取值消费者存在，未因为 completed 同名检索噪声制造“所有文件传输没接线”结论。
- identity legacy迁移已有 console命令→gateway.console_legacy_migration→legacy_identity_migration→prepare_legacy_bindings，不能继续写成“纯组件无消费者”；但 P0-01 与权限/写盘动态门槛未解除，不能称用户已经能完成旧档迁移。

## 四、明确暂不支持/不能冒充已支持

1. **LAN/P2P 崩溃房间与存档恢复**：本机 restore_local_match 及 worker 启动读取旧 recovery.json 已显式安全阻断；无密钥绑定与原子恢复契约。保持阻断并在 UI/发行说明明确说明，不能复用 dedicated 专项宣传为支持。
2. **手工邀请码模式的一键重新握手恢复**：MatchP2PInvite 提供 offer/answer，但无 reconnect/can_reconnect_session；session.reconnect_available 需要 endpoint 或 driver.reconnect。底层 resume_peer API 存在不等于大厅有完整手工码恢复流程。信令模式另有 reconnect 路径，不能混算。
3. **纯信令根项目运行**：根项目有规则 autoload；bootstrap._start_signaling、server_cli relay-only 都明确拒绝。无autoload独立信令暂存项目与重新暂存/单独发行验收必需，普通 game+relay 是双职责而非纯信令隔离。
4. **真人掉线 AI 托管、游戏流量中继/TURN兜底**：不属于支持范围；掉线应暂停，信令只交换握手，无法直连明确失败。不允许作为连通性“修复”。
5. **房主本人失去密钥且房主离线时的自助继承**：authorized_owner 要求当前房主在线认证；prepare_inheritance 拒绝 target=actor。不是首个持票者自动认领。若没有另外已认证房主/显式管理员流程，保持失败关闭，不宣称可无授权救回。
6. **协作预算等同任意原生调用硬时限、进程重启等同根事务回滚**：均不成立；硬时限需要精确原生所有者，完整 rollback 必须有可验证根检查点与独立审计，缺失时只允许明确暂停/最近完整档或重开。
7. **房间密码等于加密网络/抗离线猜测**：ENet无传输加密、盐SHA-256不是慢密码KDF；docs 已声明此安全边界，不能以身份密钥认证掩盖密码通道风险。

## 五、可由用户真人实测与动态准入门槛

### 只能在代码阻断修复、写入者结束并冻结后运行的工程验收

- 新构建 Windows/Linux，空输出目录，外置 data manifest/PCK 场景闭包/本平台信号扩展验证；记录源码与产物 SHA，不能测旧包。
- 正式 LAN/P2P/dedicated 新建房→数据选择/校验→数据屏障→选人→v2正式对局。房主机器/独立服务端机器分别确认独立规则 PID，UI无权威执行，ready 绑定 room/PID/instance/mode。
- 身份：错密钥拒绝、重复昵称显示用户名而非指纹、继承修订/序号/目标上下文过期拒绝、票据只私有交付、旧连接先安全退出再独立下一轮重连；中局必须从 v2 真入口，不手工发协议代替 UI。
- 恢复：先保存→崩溃→重启→所有原真人按绑定认证重连→数据ack屏障→恢复中局；查规则状态、待答、随机序列、日志顺序，不只新PID/ready。分别失败注入恢复写盘、票据保存、审计写盘与关闭保存。
- 安全进程：PID复用、主管消失、旧worker晚退出、旧ready污染、超时/取消/析构均只影响本次拥有的进程；禁止“return true 后跑绿”。
- 根事务：异常包含部分动作+连锁+待答+随机+日志尾部，跳过回到根前完整状态；审计事实不可随rollback抹除；没有完整检查点时禁跳过。
- 每套同时记录退出码、RESULT/checks/failures、SCRIPT/SHADER/引擎错误、当前日志指纹、窗口分支实际执行/原生画面检查。源码静态/历史绿/合成回执一律不能补动态缺口。

### 可以交给真人的体验/网络覆盖

- 不同运营商/移动热点/NAT、弱网丢包/高延迟/异地多人直连成功和失败提示；无法直连无流量中继兜底。
- 职阶选人保密、公共观战不泄露私有手牌；重复昵称列表、房主交接、主动离开与掉线的差别。
- 缓存默认开、清理后重新同步、大卡图与多玩家目录选择；真人顺位行动/目标玩家私有答复/多轮出牌、观战刷新和异常暂停提示易用性。

这些属于体验和环境矩阵，不承担证明进程所有权、持久事务原子性或未接线入口已修复的责任。

## 边界与已遇问题

扫描执行完成，但不是形式化穷尽审计；未逐张验证所有卡牌规则、未动态证明网络链或原生ABI。首次宽范围扫描把历史日志/插件备份误纳入，已缩小为生产/测试源码；大小写候选已按实际路径复核。JSON长stdout出现工具截断，已从完整工具输出解析并保存，而非补造结果。指纹变化表明当前不能放行冻结；主代理须在所有写入者停止后复核上述目标与报告行号。
