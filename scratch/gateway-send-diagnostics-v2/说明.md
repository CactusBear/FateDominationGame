# 网关发送与回执诊断补齐说明

本批只修改 server_gateway.gd 的发送、路由转发和管理员回执区块，不改身份认证、恢复绑定、权限判据或连接清理策略；不运行 Godot。enet_transport.gd 已正确消费 put_packet 的返回值，本批不覆盖该文件。

新增统一发送辅助入口：消费底层 Error，失败时只保存并发出固定阶段、连接编号、通道和错误码，不记录消息 kind 的任意文本、载荷、密钥、token、命令或隐藏牌面。诊断仅保留最近一次，避免无限累积。底层 OK 只表示入队，不表示客机收到。

外部请求到房间的转发失败：记录上行诊断，并尝试向原连接发送固定安全错误；错误回执本身失败只记录，不递归发错。内部房间到客机的转发、房间列表和绑定通知失败：记录明确诊断，尝试安全错误回执；绑定通知未成功入队时不先标记 attached。

管理员命令执行后回执发送失败：不得重执行命令；尝试发送同 request_seq 的最小回执，明确执行已返回但原结果不可用，不能把发送失败称为业务执行失败。最小回执仍失败只记录诊断。通知和踢人回执只报告入队及失败，不声称玩家收到。

身份代理独占的 send 调用只交接精确替换建议，不交叉写入。新增 scratch GDScript 专项源码直接调用真实网关，以可控底层发送失败覆盖超预算、上行失败、回执失败及不递归、不重执行和不泄漏；仅静态解析，运行验收由主代理所有写入者退出后串行完成。
