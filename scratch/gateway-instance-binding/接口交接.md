网关绑定消费者现引入 manager.process_identity_verifier:Callable，签名 (binding:Dictionary)->bool，binding={room,pid,instance_id,authority_host_mode}。默认 false；须由生命周期所有者接上真实 OS 句柄/子进程所有权校验，不允许单纯 OS.is_process_running 或 instance 字符串冒充。本代理仅编辑 manager matches_instance 后辅助区，不编辑 create/recover/poll/stop。请生命周期所有者在进程退出把 pid=-1、ready=false 并保留目录；若已有自己的句柄验证函数，可接 Callable 或主代理统一替换辅助实现。console_channel/control 的管理请求须补 room_id/instance_id/authority_host_mode；原只发 pid+instance+action 的入口不在本代理写域。
