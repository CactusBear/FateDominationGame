# 网关实例绑定实施说明

本子任务只修改 server_gateway.gd 的路由/管理实例区域及 server_room_manager.gd 的绑定消费辅助入口，保留已有策略、密钥认证和发送诊断；不修改 worker、control、console、lobby、effect、UI、transport，不运行 Godot、不读取凭证、不提交。

1. 管理器提供房间、PID、随机 instance_id、authority_host_mode 的规范绑定快照，比较时逐字段检查，不把字符串实例号当作 OS 进程身份。
2. 路由、pending、creators 保存同一绑定。恢复调用携带旧 PID/instance，并在新实例建立后重新捕获绑定；过期 pending 拒绝而不是转移到新 worker。
3. worker 消息和断线回调捕获绑定及原 link 引用；回调必须同时匹配当前路由 link 和管理器绑定。断线队列存完整路由身份，延迟处理不按裸 peer 删除新路由。
4. 实际转发、ready 和管理使用路径必须经过进程句柄验证入口；没有可信 OS 句柄验证器时失败关闭。验证器由管理器生命周期所有者接入，不能用 ready 字符串或 is_process_running(PID) 替代。进程退出登记 pid=-1 与保留目录由生命周期区块所有者完成，本代理不交叉编辑。
5. 清理路由先撤销登记，再关闭 link，避免同步断线信号污染新路由；内部断线不清除公网连接认证身份。创建者断线不能对更换后的实例调用旧停止操作。
6. 新增 GDScript 反例源码覆盖相同 PID 换 instance、相同 instance 换权威模式、旧 link 回调/断线队列和未验证句柄拒绝。仅执行 gdtoolkit 静态解析和源码契约检查，运行测试交主代理串行进行。

管理请求生产/消费在 server_console_channel.gd 与 server_room_control.gd，本代理无所有权，将缺口明确交接给相应所有者。
