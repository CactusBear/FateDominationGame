## 主代理必须接续的边界
1. **process_identity_verifier 默认未设置，故 is_ready/attach/转发全部保守拒绝**。主代理/生命周期所有者须接真实 OS 句柄校验 Callable `(binding)->bool`；不能把 ready、随机 instance 或 OS.is_process_running(PID) 单独作为证明。没有真实验证原语时保留拒绝并明确功能受限。
2. 退出 pid=-1、保留登记/目录属于管理器生命周期区，本代理未交叉修改；网关恢复只在生命周期登记 pid<=0 后触发，并携带原 PID/instance。
3. `server_console_channel.gd:_room_request` 当前仍只比 ready 的 id/pid/instance 格式，发 `pid+instance+action`；`_room_result` 还用裸 PID 存活。`server_room_control.gd` 旧消费者同样没有 room+authority_mode。它们不在本代理所有权，需对应代理补完整四元组并再读取确认。管理器 is_ready 现在至少会先拒绝未校验句柄的请求。
4. 兄弟代理仍修改 manager 生命周期/恢复路径及 gateway 独立身份区域，主代理须最终统一回读源码并重新静态解析，再决定是否执行 Godot 专项。
