## 已确定，不重复询问

- 信令交付方式：当前真人测试版先单独导出纯信令服务；正式发行版必须与独立服务端整合交付和启动管理，不能把单独部署信令作为最终交付要求。整合不改变职责边界：信令只交换握手和辅助打洞，不加载游戏规则或转发 P2P 对局流量；允许内部保持进程隔离。此项为已确认的正式发行要求，尚未完成验收。
- 主机负责规则运算；P2P/局域网主机是房主，独立服务端按房间承担运算。
- 独立服务端必须多房间，Windows/Linux 命令行运行，默认任何人能建房。
- 服务端的 P2P 中继职能只做信令与辅助打洞，禁止将它做成游戏流量转发兜底。
- 不做真人掉线 AI 托管；观战默认公共视角、无延迟。
- 房间可只用主机 data，也可选择某些玩家的部分条目；所有参与者同步必要卡图。缓存默认开，客户端可清理。
- requires 采用已确认的 A/B/C/D 处理；不自动按玩家优先级解决冲突。
- 死循环同时做开局前预检和运行时保护。随机模拟有独立开关，默认 60 秒，0 秒等同关闭；疑似耗时默认 3 秒。
- 异常通知全员，由房主决定跳过或移除房间内问题条目后重开；不删除玩家本地原始 data。
- 用户主动删除的旧视频不得恢复。

## 已确认的身份授权方案

### 管理员与白名单的首次身份绑定

- 阶段：服务端管理员、封禁、白名单与远程权限命令。
- 已查证：目前会话恢复凭据用于原房间成员恢复；计划中的客户端 UUID 不是身份证明，不能直接作为可信管理员凭据。显示名和 IP 同样不能替代稳定的用户认证。
- 用户已确认：客户端生成身份密钥，身份登记无需管理员确认，不引入独立账户平台或强制邀请流程。
- 用户补充：登记同时提交玩家自行设置的用户名与昵称；用户名在该服务端的身份登记库中不得重复，昵称允许重复。用户名与昵称均不是密钥身份的替代认证凭据。
- 用户名占用检查与登记写入必须作为同一原子操作，避免并发登记产生重复用户名；登记失败不得留下部分身份记录。
- 用户已明确用户名区分大小写，只允许英文字母、下划线、数字，不允许数字开头；客户端大厅有独立用户名与昵称输入区及连接前格式校验。登记、查重和密钥挑战认证已接入独立服务端，源码 CLI 与 Windows release 身份专项各 22 条通过；后续安全补丁仍须重新验收。
- 用户进一步确认：用户名最多 32 字符，允许修改用户名，但身份密钥保持不变。改名仍须通过相同格式校验及区分大小写的唯一性检查；更新失败保留原用户名，管理员授权、封禁和白名单不随改名丢失或转移。实际窗口登记、同密钥改名、管理员入口实时授予和撤销专项 11 条通过，截图已原生检查。
- 房间密码可选，由房主设置；默认无密码。大厅新增遮蔽输入、房主设置按钮及权威状态反馈；新玩家和观战者经权威密码校验，原成员凭据重连不重新登记。空值取消密码，仅大厅房主可修改，设置失败保持原状态。源码 ENet 密码及用户名专项 26 条、恢复兼容专项 20 条、实际窗口输入与设置专项 9 条通过，画面已原生检查；发行包与各类传输仍需补验。
- 私钥由客户端保管；服务端以公钥及其指纹识别玩家，并验证客户端持有对应私钥，不能只信任自报身份字段。
- 身份登记与准入授权分开：未启用白名单时，无需管理员逐人批准；启用白名单时，按密钥身份核对授权，不以显示名或 IP 代替身份。
- 管理员可以管理已经登记密钥身份的玩家；普通身份自动登记不等于自动获得管理员权限，管理员授权、封禁与白名单均以稳定密钥身份为目标。
- 此项设计决策已解除阻塞；身份认证、权限命令及持久化已有代码和专项证据。新增发现的恢复凭据与密钥绑定缺口正在修复，不能把上述专项当作所有模式的安全交付。

## 实施技术风险，不当成用户选择题

- `capture_rule_state()` 不完整；不能仅靠其相等宣称无误判死循环或完整恢复。
- 只有两个 STUN 端口不能保证准确识别所有 NAT 类型；普通 WebRTC ICE 应由 WebRTC 实现处理，不能擅自以“判定对称 NAT”拒绝实际可能成功的连接。
- 任意 JSON 效果不是天然沙箱；允许的数据原语、文件路径与资源预算需要做技术验证，不能下载并执行客机 GDScript。
- 存档恢复目前采用显式录制入口；普通 UI 和调试操作的覆盖必须验证后才可开放自动录制。未接入路径不能默默漏记。
- 真实异地网络、Windows/Linux 导出和画面验收必须有实际工具证据；缺环境时列为未验收，不用模拟结果替代。
- 房间密码当前使用随机盐的 SHA-256 校验值，仅防止原文落盘和公开快照泄露，不提供抗离线穷举保证；ENet 本身不提供加密，密码传输及在线猜测限流仍需安全加固，不得称为已完成安全认证。首次建房默认无密码，目前房主在进入大厅后显式设置；创建前预设需独立接线，不能误称输入框预填即已保护房间。
