# 后台内容检查

## 已修改并验证

- 关闭内容弹窗只收起，不取消本机准备或服务器校验。
- 独立“取消检查”按钮显式取消，退出大厅仍执行原安全取消。
- 隐藏时继续轮询服务器请求、处理结果；重新打开仍保留当前请求，不重新configure取消旧任务。
- 有风险结果隐藏时仅提示待确认；重新打开再展示风险确认，不擅自批准。
- 大厅显示后台检查状态，完成后刷新为下载/准备等下一步提示。

源码回归：关闭不取消与显式取消专项3项通过；真实窗口一真人五AI，鼠标开启检查并收起窗口，后台检查应用完成、随后下载准备选人进入正式战局，22项通过。

当前发布的v7压缩包不含这次修改，尚未导出下一版。

## 与耗时问题的区别

允许后台检查解决的是窗口占用，不等于检查耗时已经缩短。完整流程仍包括素材准备、隔离进程启动、重复素材校验与组装、角色/规则加载及可选开局前试运行。此前22%的提速只针对初始文件校验，不可当成全链数字。

全部测试输出在E盘，每次启动显式指定E盘APPDATA和LOCALAPPDATA。
