# 所选房间数据加载进度

## 已实际验证

- 房主本机条目勾选、搜索、批准清单生成、显式基础集合。
- 按来源选择解决同名内容冲突；未解决冲突和缺失 requires 拒绝生成清单。
- 独立进程只组装批准文件后实际加载规则；未知操作、损坏 JSON、缺少可用阵容拒绝。
- JSON 大小字段仅接受有限且预算内的整数；不放宽网络文件清单约束。
- power_query 使用现有只读解释器的描述登记表；补接已有 is_true_name_released 读取，不写日志。
- 御主和从者目录扫描只向下遍历，不再依赖 /data 目录后缀。
- 权威采用批准数据，房间规则版本与清单版本一致才允许正式大厅开局；离房恢复本地规则根和缓存位置。
- 非 headless 真实点击数据弹窗、应用、离开；检查 net_data_selection.png 无越屏布局。
- 非 headless 大厅同步客机后选人、进入正式 v2；管理权转让、观战与踢人测试通过。
