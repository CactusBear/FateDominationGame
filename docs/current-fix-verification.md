# 当前修复与最终验收报告

## 已修复

### 稳定性与效果结算

- 修复完整对局偶发崩溃：`BaseHandCard.edit_cost()` / `edit_power()` 将合法的空增量解释为“不做增量”，不再把 `null` 传给 `BaseNumber.add()`。
- 修复手动对局进入调试断点：AI 效果链取不到目标攻击牌时，`PlayAttack` 的默认参数在函数体保护前解引用空对象。`PlayAttack/PlaySkill/AddAttack/AddSkill` 现统一先判目标，再补费用/威力默认值；缺目标安全失败且不写出牌事实。
- 效果提示在同一窗口按文本去重，同一时点的多条效果统一折叠后推送，不删除任何正常刷新入口。
- 效果提示与玩家战报只展示实际执行了动作的效果；条件不成立、参数无效、占位 `do_nothing` 不再宣称生效。
- `PLAYED_CARD` 携带实际卡对象；“此牌打出时”由数据声明 `source_bound`，与“每当你出牌时”的独立监听分开。
- 卡牌效果状态检查兼容 `WeakRef` 来源，未激活技能不会绕过 `_is_activating` 检查。
- 时点批次编号正常递增；等待玩家答复时，后续时点保存玩家时点快照并按到达顺序排队，不再覆盖当前选择。
- 效果结算只消费瞬时事件时点，保留当前玩家的阶段窗口；万符必应破戒等在行动阶段先结算其他效果后再打出的技能仍可正常执行并写入战报。
- 延迟效果支持显式到期时点。令咒“获胜后获得战果”在本回合 `day_end` 未触发时注销，不会跨回合残留。
- 暗置事件的战区效果在翻明前不参与 `MapAreaHasEffect` 查询，翻明后立即生效。
- 搬牌操作先校验来源和目标下标，再摘出并插入；非法下标不会让卡牌从两个区域同时消失。

### 常规出牌与 AI

- AI 先无副作用搜索完整出牌组，再一次调用 `RegularPlay.submit_group()`；第一张牌结算后改变的上限不会反向扩充本组。
- 待确认明暗模式会验证选择后仍存在完整合法出牌路径，不再允许玩家进入剩余牌全不可选、又未达到最低要求的死路。
- 保留 AI 的技能牌优先策略，但所有合法性、数量、费用和明暗判据继续复用 `RegularPlay`。
- 无限剑制仅响应自身打出，激活后把常规出牌范围设为 0～4并禁止抽牌；手牌归零时恢复 2～2和抽牌权限后关闭。
- 已打出区的同名牌逐张平铺，不再合并显示 `×N`；手牌与待确认牌仍保持逐张交互。
- 点击待确认卡的实际卡图可精确撤回该卡，克隆卡位不会误撤上一张；撤回后同步关闭已失效的整组确认框。

### 卡牌、技能与规则

- 真名解放覆盖从者技能区、御主技能区、御主附带技能、侧边技能、手牌、出牌区、牌库与弃牌；同一对象按身份去重。未觉醒升华技仍保持升华技卡背，不会被真名解放错误觉醒。
- 御主 `upgrade_skill` 加载时保留正确类型，不再把未觉醒升华技当作已使用效果登记或展示。
- 卫宫士郎附带技能按对象身份去重，不再重复显示两张干将莫邪。
- 牌背分支和未觉醒升华技卡背会清除复用卡位遗留的【改】徽标。
- “遏制第三方威胁”的攻击判据按有威力并计入场上的手牌对象处理，不窄化为 `BaseAttack`；十二试炼等满足条件的技能牌可获得威力。
- 令咒数值修改支持由数据声明上下限；间桐慎二“小丑”和万符必应破戒等扣减不会把令咒降到 0 以下。
- 玩家拥有可修改的 `command_spell_limit`；“遏制第三方威胁”恢复令咒读取当前上限，不超过上限，也支持上限高于 3。

### UI 与战报

- 令咒说明使用固定高度、隐藏滚动条的滚动区域；容器横向扩展，完整文字可滚动且不会撑高底栏。
- 本地与对手有可浏览的游戏外卡时动态显示入口；仅收集真实 `BaseCard`，不把状态对象当作卡牌。
- 游戏外入口显示真实卡数；本地入口扩大并使用金色装饰，对手抽屉在远坂凛使用宝石后会动态显示已用宝石入口。
- 重复牌数量角标固定落在卡图右上角内部；弃牌堆、游戏外等通用浏览器点击面板外即可关闭，且不会点穿战区。
- 状态栏 buff 支持左键查看说明；buff 数据可显式关联持有者现有效果。葛木“局外人”展示工房禁魔、离开工房移动折扣和战斗阶段战果效果。
- 战报使用显示名并输出玩家可读事实：谁打出什么牌、什么时点由什么来源发动了哪条具体效果、选项、魔力/战果变化、真名解放、令咒、战斗结算与终局。内部 `time_point` 和未知英文类型不进入玩家战报。
- 抽牌事实继续保留具体对象供规则查询，但玩家战报只显示“抽牌”，不公开抽到的牌。
- 局势牌、事件牌借用玩家 id 作为结算顺序锚点时，提示不会把锚点玩家显示成发动者；“深山町的杀人魔”等效果只显示真实场上牌来源。
- AI 出牌浮层始终向顶栏上方展开并限制在视口内，不再落入战区标题带；终局显示“对局已结束”，不再出现“玩家 -1 行动中”。
- 对手与本地已打出牌都逐张显示；牌背、异常放大和卡位复用状态已清理。

- `card_keyword_test`：23 项。覆盖真名解放的从者技能、御主附带技能、隐藏真名及升华技不觉醒。
