# 主机对局与网络视图接线增量

## 本批实现

- `scripts/net/match_authority.gd`：使用已完成的选人分配和初始顺位调用既有 GameStart；显式登记 remote/ai，未知座位默认为 vacant；不实例化战局界面。
- ViewBuilder 只在权威端生成视图；按连接映射观察者，未分配座位只生成公共视角。记录每个连接最近收到的视图序号和权威修订号。
- 指令白名单目前只有 end_action 与 deploy；拒绝观战操作、过期视图、非当前行动者与未知方法。不允许消息直接提供 player_id 决定操作对象。
- 部署复用 DeployRules，要求前哨阶段、尚未部署、无等待效果，战区必须来自当前对象 ID 表且可部署；部署与结束行动分开提交，重复部署不会再给收益。
- LobbySession 接入 begin_match、match_bind、match_view、match_command，视图经可靠通道 1 传输并由 ViewMirror 接收。大厅按实际帧 delta 推进主机驱动，不以 0 时间冻结 AI 冷却。

## 已执行的专项

- net_match_test：21 checks 通过，无运行错误。测试曾因部署断言分支未进入而出现虚假通过，已增加明确进入前哨阶段断言；实现部署前真实报红，实现后通过。
- net_lobby_test：25 checks 通过，无运行错误。包含入房、分块传输、网络选人、主机开局、客机接收过滤视图、指令部署以及断线保留真人席位。
- 本批无新增规则原语，不修改卡牌 data 或部署规则。

## 仍未完成，不能宣称完整网络对局可玩

- 本批主机开局入口是会话协议专项，尚未添加正式 UI 开局按钮或将 v2 改成纯镜像读取。
- 常规出牌、移动、主动发动和等待选择等指令尚未接到权威网络入口；人类仍可能停在未支持的输入窗口，不能以当前部署成功推断可完成整局。
- 正式开局还应等待数据清单同步与预检完成；当前内部 begin_match 协议尚无这些就绪屏障，因此不向主菜单开放。
- 观战中途加入后的视角绑定、重连认证、多个座位控制者、房主转让及连接失效指令的进一步边界测试尚未完成。
- 当前网络专项仍为单进程两个 ENet 端点，不等同跨进程、跨设备、公网或 Linux 验收。
- 独立服务端、P2P、死循环保护及之前文档所列未完成项仍未完成。
