# 数据传输与网络选人增量

## 已实现并实际执行

- `blob_receiver.gd`：由本地批准来源、哈希和大小后接收分块；来源、偏移、分块长度、总预算校验；完整内容交给缓存校验哈希；拒绝、断线及完成时释放接收预留。
- `lobby_session.gd`：发布主机明确选择的内容，已入房成员按哈希请求，可靠通道 2 分块发送，每次 poll 限量轮转发送；未发布内容返回专用失败消息并释放客机预留。
- `selection_authority.gd`：复用既有选人模式和 DummyBot，不复制抽取算法；显式连接与座位映射；拒绝代选他人座位、重复御主；公共和私人选人视图均不携带从者归属。
- 大厅新增开始选人、御主下拉框及提交按钮。主机登记本地配置，客机不能通过消息提交脚本路径。网络选人完成后保留既有规则产生的初始顺位。

## 专项结果

- net_blob：41 checks 通过，无运行错误；真实 ENet 分块收发与磁盘缓存，不是模拟传输。
- net_lobby：19 checks 通过，无运行错误；入房、文件传输、缺文件失败回收、准备、权限拒绝、主客机与 AI 选人、掉线保留。
- net_selection：11 checks 通过，无运行错误；显式非连续座位、控制权限、AI 分配和隐私字段。
- net_lobby_window：10 checks 通过，无运行错误；真实鼠标建房、准备、开始选人及提交御主，远端完成选择。已原生查看完成后的截图 `tests/runtime_reports/net_lobby.png`。
- `multiplayer-blob-results.json` 保存了选人接线前的传输批次原始结果；其中 net_lobby 的 14 checks 和窗口 5 checks 是旧批次，不改写成新批次数值。

## 限制与未完成

- 文件收发接口已接入会话，但房主勾选条目、清单交换、自动下载全部素材、房间 data 组装、全员校验确认尚未接完。当前测试内容是明确的测试负载，不宣称实际全量卡图同步已验收。
- 文件接收暂保存在受限内存缓冲；尚无跨断线持久化续传、超时回收及总缓存 LRU。
- 选人已贯穿大厅与网络，但没有进入可玩的网络对局，完成提示明确标示这一点。
- 当前验证为同一进程里的两个真实 ENet 端点；非跨设备、非跨进程验收。
- 后续仍需锁定房间模式与本地注册配置一致性、完善选人消息结构校验，以及房主转让后的 UI 状态；不将已有专项覆盖当成这些已完成。
- P2 客机视图及合法指令、完整战局、P2P、独立服务端、死循环保护及主菜单入口仍未完成。
- 本批无新增需要用户决定的问题。
