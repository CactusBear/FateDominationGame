## 交互口径
- 可出牌：金色呼吸框（判据：本人行动阶段、常规出牌未达 2、魔力足够；技能区牌需魔力≥8）。悬浮卡顶只显示规则允许的「明置/暗置」。选择后立刻标记待出；「出牌」进入出牌区；常规出牌满 2 才能「结束阶段」。
- 敌人回合：横列该玩家金色呼吸高亮 + 圆内红色横幅（御主头像+名）+ 提示条转红。
- 右键任意卡放大；放大层列出类别、属性、魔力消耗、威力、每条效果。

## URL 参数（截图/自测）
`?state=enemy` 敌人回合 · `?hand=up&sel=0` 手牌悬浮+已选 · `?strip=miyama` 展开卷轴 · `?map=shinto&strip=workshop` 切主图 · `?groups=many` 多出牌组 · `?zoom=skill:对魔力` 放大 · `?board=1` / `?log=1` · `?debug=1` 输出矩形 · `?selftest=1` 输出可出牌判定。
