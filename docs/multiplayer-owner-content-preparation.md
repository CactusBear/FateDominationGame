# 房主内容自动准备

## 改动

服务器房主客户端在大厅收到已批准的内容版本及文件清单后，复用RoomDataSync自动准备，不要求点击下载。本机同哈希素材及缓存沿用既有复用机制，缺少或不同的文件才补齐。保留服务端与客户端的内容一致性屏障，不凭房主身份直接标记已同步。

完成版本不重复启动；当前版本失败不循环重试，显示实际原因和“重试准备本局内容”。客机保留下载入口；房主正常情况下隐藏下载入口。LAN/P2P本机权威沿原有准备路径，不另启动客户端同步。新版本仍需核对，旧版本错误不能代替新版本结果。

## 验证

先改实际窗口夹具，未实施时因房主未自动准备返回失败；实现后真实服务器、一真人五AI窗口测试21项通过。使用CountingSession覆写真实download_blob记录请求，实际批准内容自动准备完成且网络文件下载请求为0。真实鼠标准备、选人、进入战局通过。

错误提示专项4项通过，保留错误原因与未同步不能准备的屏障。原生查看selection.png，大厅显示房间数据同步完成，房主下载按钮隐藏，六席未见新增色块或遮挡。

## 边界

0请求结论仅覆盖本机内容与服务器批准内容相同的实际用例；远端服务器提供不同数据时仍需补齐，不能保证任何房主一律零下载。当前v7发行包尚不含此修改。
