# 真人反馈：启动器退出与素材耗时

## 反馈与验收

1. 退出启动脚本不关服。区分游戏服务与纯信令；只操作本次启动且OS句柄确认的进程。游戏服务必须先保存再退出，保存失败不能强杀；Windows直接强杀不能冒称可保证保存。候选由launcher任务调查，未合并验收。
2. 服务器内容检查太慢。分阶段测量复制/内容校验/规则加载/试运行；保持数据校验与批准屏障，不能关闭检查冒充优化。候选由validation-perf任务调查，未合并验收。
3. 客机内容同步太慢。传输重复读整文件及重复哈希由transfer-perf任务调查，未合并验收。
4. 下载前先检查哈希，同内容不重复下载。已在源码room_data_sync接入本机调用方显式指定的原始data根；校验文件大小与SHA256，相同内容进入既有缓存再安装，不同文件名可复用，不按路径猜测。损坏或非匹配内容走正常下载；路径链接和安全范围检查保留。
