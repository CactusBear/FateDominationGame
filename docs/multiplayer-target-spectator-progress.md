# 客机目标选择与中途观战增量

## 已完成并验证的范围

- 网络答复组件新增选玩家、选牌、选地点列表。名称只从当前过滤视图读取，不访问规则对象，不猜未公开卡牌身份。
- 必选牌自动选中；真实 Ctrl 点击取消会恢复必选状态。确认仍交给权威入口复验。
- 非 headless 测试用真实鼠标依次选择玩家、该玩家的暗牌、必选牌和地点，并通过真实 ENet 发送答复；选玩家→选目标玩家的牌→结算的连续界面转换通过。
- 中局观战者入房后收到单独的公共观察者绑定及当前局面，不收到私有手牌和待答提示。原有玩家不被重新绑定。
- 多个连接接近同时断开时，ENet 回调中广播可能指向已失效但尚未回调移除的连接。本批根据实际运行 API 增加已连接集合与 ENetPacketPeer 状态检查，失效目标返回 ERR_UNAVAILABLE，不再产生通道数为 0 的发送错误。

## 未完成与限制

- 正式 v2 战局仍未接纯网络镜像，独立组件测试通过不能替代实际入口验收。
- 客机选牌当前为文本候选列表；未出现在过滤视图中的卡牌只写“未公开卡牌”。效果允许临时查看牌面的显式授权与卡图呈现仍需补齐，不能自动把全部候选牌翻开。
- 非确认类目标选择的取消入口尚未接齐；当前仅支持合法候选提交，不伪装成完整取消语义。
- 中途观战本批验证的是接收协议，正式观战战局呈现、跨进程与跨设备验收仍未完成。
- 完整房间 data 选择/组装/同步、P2P、独立多房间服务端、死循环保护及掉线恢复菜单仍未完成。
- 本批没有新增必须询问用户的问题。
